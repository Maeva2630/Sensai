# SensAI

SensAI is a local, command-line AI assistant intended to help teachers prepare lessons,
activities, and educational resources. It connects to Ollama and can use local documents,
tools, and configurable assistant personas. Responses are generated by a model and should
be reviewed by the teacher.

## Quick start

Requirements: Python **3.11+**, [Ollama](https://ollama.com/), and the local project
checkout. In the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Start Ollama in another terminal if it is not already running:

```bash
ollama serve
```

Then, from your project terminal, download the default models and start SensAI:

```bash
ollama pull llama3.2
ollama pull nomic-embed-text
python3 source/main.py
```

Inside SensAI, type `/help` to list commands, ask a question, and enter `exit` or `quit`
to save the session and leave. Model names, server address, features, and settings are
configured in [`config.json`](config.json).

See the [user guide](docs/user-guide.md) for the full setup, Windows activation,
an example document workflow, and troubleshooting. The complete
[configuration reference](docs/configuration.md) explains the file format, location,
required sections, optional settings, defaults, and validation.

## Features

| Feature | What it does | Details |
| --- | --- | --- |
| RAG | Indexes supported local documents and source files, then retrieves excerpts to inform answers. | [RAG guide](docs/features/rag.md) |
| Tools and MCP | Offers a native local time tool and tools supplied by configured local MCP servers. | [Tools and MCP](docs/features/tools-and-mcp.md) |
| Personas | Configures assistant roles and switches between them during a conversation. | [Personas](docs/features/personas.md) |
| Sessions and profile | Saves conversation messages and includes a local user profile in the system prompt. | [Sessions and profile](docs/features/sessions-and-profile.md) |
| Observability | Provides local logs, on-demand prompt inspection, and an optional metrics dashboard. | [Logging and monitoring](docs/features/observability.md) |

Current limitations: scanned PDFs need OCR, which is not implemented. The separate
`memory_enabled` setting is reserved and does not activate long-term memory. `/load`
does not currently replace the active model history; use `--session` at startup instead.
The current chat flow skips RAG retrieval when a tool is offered for the question. See the
feature guides for details and privacy considerations.
