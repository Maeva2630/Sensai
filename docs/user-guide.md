# User guide

[Home](../README.md) · [Features](features/README.md)

This guide uses commands for a Linux or macOS terminal. Run the commands from the
repository root unless stated otherwise. Lines beginning with `You:` are entered inside
SensAI, not in your shell.

## 1. Prerequisites

- Python **3.11 or later**, including `venv` and `pip`.
- [Ollama](https://ollama.com/) installed locally. You will need enough disk space and
  memory for the selected models.
- The SensAI repository available locally. Open a terminal in its root directory.

Check your Python version:

```bash
python3 --version
```

## 2. Create a Python environment

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

On Windows PowerShell, activate the environment with `.\.venv\Scripts\Activate.ps1`
instead of `source`. The same dependency installation command then applies. Run
`deactivate` when you want to leave the environment. On Linux, a missing `venv` module
may require the Python venv package supplied by your distribution.

## 3. Start Ollama and download models

Start Ollama in a separate terminal if it is not already running:

```bash
ollama serve
```

Leave that terminal open. In another terminal, download the default chat and embedding
models once:

```bash
ollama pull llama3.2
ollama pull nomic-embed-text
```

The chat model generates answers; the embedding model is used to index and search
documents. If Ollama is already running as a service or desktop application, another
`ollama serve` may report that the address is already in use; use the existing server.

## 4. Review the configuration

The repository's [`config.json`](../config.json) contains the model names, server URL,
temperature, context size, features, RAG settings, logging, monitoring, and personas.
It is read at startup. For example, the defaults include `llama3.2`,
`nomic-embed-text`, `http://localhost:11434`, and a temperature of `0.2`.

Keep all required sections when editing the file. Set `model.chat_model` and
`model.embedding_model` to installed Ollama models. A higher temperature can produce
more varied answers; a larger `context_window` may require more memory and processing
time. Neither setting guarantees factual accuracy. Restart SensAI after editing the file.
See the [configuration reference](configuration.md) for the exact file location, complete
JSON structure, accepted values, optional sections, persona prompts, and MCP distinction.

## 5. Start SensAI

From the repository root, with the virtual environment active:

```bash
python3 source/main.py
```

Ask a question, or type `/help` to list the registered commands:

```text
You: Suggest a short exercise about fractions for my students.
Assistant: ...
You: /help
```

The labels can be colored in an interactive terminal; set `NO_COLOR` before launching
to disable colors. Where Python's `readline` is available, use the left/right arrows to
edit a line and up/down arrows to revisit previous input.

Enter `exit` or `quit` to save the session and leave. `Ctrl+C` and `Ctrl+D` also end the
session. See [sessions and profile](features/sessions-and-profile.md) for resuming a
conversation and privacy considerations.

## 6. Try document-grounded answers

Create `planets.md` in the repository root with this content:

```markdown
# Planet Earth
Earth is commonly called the Blue Planet because most of its surface is covered by oceans.
```

In SensAI, index it and enable RAG:

```text
You: /ingest planets.md
You: /rag on
You: According to the document, why is Earth called the Blue Planet?
```

SensAI retrieves passages and sends them to the model. A source line may identify
`planets.md` and its chunk. Answers are generated by a model and can be wrong: check the
source. See the [RAG guide](features/rag.md) for formats, filters, source display, and
configuration.

## Troubleshooting

- **`No module named pip` in `.venv`:** try `python -m ensurepip --upgrade` with the
  environment activated, then `python -m pip install -r requirements.txt`. If
  `ensurepip` is unavailable, install the distribution's Python venv/pip packages or
  create a new environment after checking its documentation.
- **Ollama connection error:** confirm Ollama is running and `model.base_url` in
  `config.json` points to the correct server. The default is `http://localhost:11434`.
- **Model not found:** run `ollama pull llama3.2` or `ollama pull nomic-embed-text`, or
  pull the model names configured in `config.json`.
- **Configuration error:** check JSON syntax, required sections, and field values in
  `config.json`; restart after making changes.
- **No useful RAG answer:** make sure the file was indexed, `/rag on` is active, and any
  metadata filter is appropriate. Check the configured relevance threshold and verify
  the source document yourself.
- **PDF contains no extractable text:** scanned/image-only PDFs need OCR, which is not
  provided by this ingestion pipeline.

For development checks, see [testing](testing.md). For diagnostic logs, see
[logging and monitoring](features/observability.md).
